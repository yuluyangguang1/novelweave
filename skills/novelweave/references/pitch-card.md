# 选题评分卡（pitch card）

一句话：**动笔之前先问这个选题本身立不立得住**。机检（`nw-continuity`）查的是写出来的
东西哪里错了，这张卡查的是还没有正文的时候能看出来的四件事。

判据只有一份：`src/core/pitch.js`。网页上那张卡、`scripts/nw-pitch.mjs`、
生成向导的确认弹窗，全部调它。改判据就是改这个文件，改完下面这些测试会红：
`tests/pitch.test.mjs`（每维正反夹具）、`tests/guards.test.mjs`（不许在界面或 CLI 抄第二份）。

## 四维与阈值

每维 0–3 分，满分 12。分档只是话术：`≥85% 可以动笔`、`≥60% 先改弱项再动笔`、
更低 = 建议换角度。**任何一处都不因分低而拒绝生成或拒绝建档**，CLI 恒退 0。

| 维度 | 判什么 | 3 分 | 0 分 |
|---|---|---|---|
| `hook` 开篇钩子 | 一句话梗概／首章拍点／首章成稿结尾里有几处收在**问句**或**突转词**上 | ≥2 处 | 没有任何可判文字 |
| `diff` 题材差异 | 内置手写套路词表的命中数；给了对照书时再加一条撞车 | 一个没命中 | 命中 ≥3 个 |
| `structure` 结构完整 | 每章有拍点／主角有性格／有对抗方或未收的伏笔，三项各 1 分 | 三项齐 | 全缺 |
| `length` 篇幅匹配 | 目标字数 ÷ 章数 是否落在单章区间 | 区间内 | 没填目标字数 |

写死的数（都在 `pitch.js` 顶部，改它们必须连测试一起改）：

- 突转词与问句判据**不在这里**，取自 `NWTension.hookKind` —— 与 R17 同一批词，
  两条规则不会一个说有钩子一个说没类型。
- `LENGTH_RANGE = { long: [1200, 4000], short: [400, 4000] }`。下限贴着
  `NWTension.QUOTAS.*.minBody`（低于它那一章连"基本成形"都不算），上限是读者的单次耐心。
  超出但不到 2 倍算"能调"（2 分），更远算"撑不起"（1 分）。
- `BODY_MIN_FOR_HOOK = 200`：首章正文不足 200 字时**不拿它的结尾参与判分**。
  没有这一条，大纲章的尾巴会冒充成稿钩子。
- `SIMILAR_CUT = 0.5`：梗概与对照书的大字符（bigram）Jaccard 重合过半算撞车，计一次命中。
- `CONFLICT_RE`：梗概里出现"但／却／被迫／只剩／必须／秘密…"这类词，说明作者至少写清了
  谁跟谁拧着 —— 只作为**有对抗方**的一种证据，不代替伏笔账本。

## 这套东西不测什么（同样是判据的一部分）

`题材热度`、`平台榜单`、`爽点强度`、`文笔好坏`、`作者粉丝量` —— 本机没有任何榜单数据源。
要把这些写进去，只能拿一个手写词表冒充热度，那是骗作者。所以 `CLICHE_WORDS` 那二十几个词
在卡上、在 CLI 的 `rubric` 里、在向导弹窗的说明行里都**明说是手写的**，
它测的是"像不像照着模板填的"，不是"卖不卖得动"。

同理，`structure` 那三项查的是**登记过的东西齐不齐**，不是"人物有没有深度"。

## 命令行

```
node scripts/nw-pitch.mjs rubric [--json]          # 摊开判据与词表
node scripts/nw-pitch.mjs score [bookDir] [对照书目录…] [--json]
node scripts/nw-pitch.mjs score --concept 梗概.json [--genre G] [--words N] [--format short|long]
```

- `score` 可以省：在书目录里直接 `nw-pitch.mjs <bookDir>`。
- `--concept` 吃的是生成侧那份梗概 JSON（`title/logline/characters[]/chapters[]/world[]`），
  它不落库，所以只能在命令行上给。
- 不给对照书就不查撞车，卡上会如实写"未查"。**被评的那本永远会被从对照表里剔掉**，
  否则每本书都跟自己撞车。没比成的原因有两种，话术也分两种：
  「未给对照书，本题材是否撞车未查」/「对照只有这本书自己，撞车未查」——
  作者明明给了 `--against`，却被说成"没给"，那是撒谎。两种"没比成"的话术是分开的：`未给对照书` 与 `对照只有这本书自己`，
  给了 `--against` 却被说成没给，那是在撒谎。
- 退出码：0 · 2 用法错 · 5 读盘错。分数低不是错误。

## 网页上在哪

两个 AI 起书向导（短篇 / 长篇）的**确认弹窗顶部**。建档之前那一刻是这张卡唯一有用的时机：
作者还能改。弹窗里改完点「按我改的内容重新评分」，卡片读的是与建档同一个解析函数
（`readConceptForm`），所以"评分看的"与"建档存的"必是同一份内容。
库里其它书的梗概自动作为撞车对照（同名的剔掉）。分数不拦建档。
